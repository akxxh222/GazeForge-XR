# Project milestones

| Stage | Work | Result |
| --- | --- | --- |
| 1 | Native GNM import, UV checks and metric calibration | Complete |
| 2 | Five skin/eye looks, layered eye materials, skin detail and strand hair | Complete; visual limits are listed in the README |
| 3 | Eye aiming, lids, brows, attached details and timeline actions | Complete |

Each stage builds on the previous one. The scene and exported maps keep the native GNM topology and UVs. We keep measured checks separate from appearance judgements; passing the controller tests does not establish photorealism.
